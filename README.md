# 📷 ASCII Art Converter (Python)

A lightweight Python tool that converts images into **ASCII art**, with two output modes:
1. **Pure text** (`.txt` or printed to terminal)
2. **Rendered image** (`.png` with styled ASCII characters)



---

## 📋 Requirements

- Python 3.7+
- [Pillow](https://pypi.org/project/Pillow/) (`PIL`)

### Install dependencies

```bash
pip install Pillow
